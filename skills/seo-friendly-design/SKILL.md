# Seo Friendly Design

SEO is a design concern. Get the foundation right; content does the rest.

## Semantic HTML

One h1 per page. Heading hierarchy logical. <main>, <nav>, <article>, <footer> used. Schema.org structured data.

## Meta tags

Title (50-60 chars). Description (150-160 chars). OG tags for social previews.

## Page structure

URL slugs descriptive. Sitemap.xml. Robots.txt. Canonical tags for duplicate content.

## Internal linking

Related-content links. Topic clusters. Avoid orphan pages.

## Common mistakes

Multiple h1s per page. No meta descriptions. Title tags duplicated. No sitemap. Single-page apps without server-rendered HTML.
