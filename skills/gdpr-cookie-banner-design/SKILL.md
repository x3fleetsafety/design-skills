# Gdpr Cookie Banner Design

Cookie banners are required in many jurisdictions. Compliant + non-annoying is achievable.

## Required elements (EU)

What cookies / data. Why. 'Accept all' / 'Reject all' / 'Customize' — all equally prominent. Granular controls if customize.

## Don't dark-pattern

Accept button bigger than reject is a dark pattern (and increasingly illegal). Equal-prominence required.

## Banner placement

Bottom of page, sticky. NOT a full-screen overlay that blocks content (unless legally required).

## Granular categories

Strictly necessary (always on), Analytics (optional), Marketing (optional), Personalization (optional). Each toggleable in 'Customize'.

## Persistence

Save preference. Don't re-show unless user clears cookies or you change cookie types.

## Common mistakes

Tiny 'reject' button vs huge 'accept'. No granular control. Banner re-appearing every page. Blocking content with banner. No clear way to change preferences later.
