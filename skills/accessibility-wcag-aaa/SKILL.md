# Accessibility Wcag Aaa

WCAG AAA is the highest standard. Not legally required in most jurisdictions; signals high-quality + inclusive design.

## AAA vs AA differences

Contrast: 7:1 for body text (vs 4.5:1 AA). 4.5:1 for large text (vs 3:1). Plus enhanced requirements for sign language, audio descriptions, etc.

## When to pursue

Government, healthcare, public services. Premium B2B SaaS for prestige. Not always achievable for all content.

## Trade-offs

Higher contrast restricts color palette. Sign-language requirement adds production cost. Audio descriptions add to video production.

## Path to AAA

Start with AA. Audit AAA gaps. Plan remediation per surface.

## Common mistakes

Claiming AAA without auditing every page. Sign-language requirement ignored. Audio descriptions skipped on video content.
