# Terms Of Service Design

Terms of service should be read once, agreed to once, and updated transparently.

## Display

Two-layer presentation (summary + legal). Anchored sections. Last-updated date. PDF download option.

## Click-through

Sign-up form has 'I agree to the Terms and Privacy Policy' checkbox. Links open in new tab. Checkbox unchecked by default — user actively opts in.

## Audit trail

Record IP, timestamp, version-id when each user accepts. Critical for legal defense.

## Updates

Material changes require re-acceptance on next login. Minor changes communicated via email + change log.

## Common mistakes

Pre-checked checkbox. No version ID stored. Terms link opens in same window (loses signup state). No change log. Bundle ToS + Privacy + Cookie all into one mega-acknowledgment.
