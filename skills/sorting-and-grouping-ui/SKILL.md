# Sorting And Grouping Ui

Sort + group transforms a table from data dump to dashboard.

## Click to sort

Click column header sorts asc. Click again desc. Click third reverts to default. Visible indicator (arrow up/down).

## Multi-column sort

Shift-click adds secondary sort. Display order: 1st, 2nd, 3rd sort columns indicated.

## Default sort

Pick the most common useful sort. Show indicator that this is the default.

## Grouping

By column value. Group headers collapsible. Aggregate row (count, sum, average) at top of group.

## Common mistakes

No sort indicator. Inconsistent default sort (different tables sort differently for same data). Multi-sort hidden / unintuitive. No group totals.
