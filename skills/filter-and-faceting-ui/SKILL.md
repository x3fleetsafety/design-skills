# Filter And Faceting Ui

Filters narrow data fast. Done well, users find what they need in 2 clicks.

## Facet types

Checkbox (multi-select). Radio (single-select). Range slider (numbers, dates). Tag input (free-form). Toggle (boolean).

## Apply pattern

Apply-as-you-go (live filter on each click) for fast filtering. Apply-button when filter set is complex / expensive.

## Active filters display

Show active filters above results as removable chips. 'Clear all' button.

## Saved filter sets

Power users: save filter combinations as named views ('Drivers with expiring CDLs').

## Common mistakes

10 facets all expanded by default (overwhelming). No way to clear all. Apply button when single-click is faster. No saved views for repeat tasks.
