# Social Proof Systems

Social proof is "people like me chose this." Different surfaces need different proof.

## Forms of social proof

| Type | Conveys |
|---|---|
| Named customer logos | "Real companies use this" |
| Customer count / fleet count | "Lots of people use this" |
| Industry-specific logos | "Companies like mine use this" |
| Testimonials | "Real outcomes" |
| Case studies | "How it works in practice" |
| Press / media logos | "Reputable outlets covered this" |
| Integration logos | "Works with my stack" |
| Star ratings | "Quantified reputation" |
| Awards / certifications | "Industry recognized" |

Mix forms — don't rely on one.

## Customer logo bar

Most common pattern. Placement:
- Below hero (first impression)
- Standalone section mid-page
- Footer (low priority)

Rules:
- 4-8 logos in a row
- Grayscale or low-saturation (consistent treatment)
- Same height for all logos
- Padding between logos generous
- "Trusted by" or "Customers" label above

## Customer count

If you have a meaningful number:
- "Trusted by 500+ small carriers"
- "Used by 12,000 dispatchers"
- "$2B in compliance value protected"

The number should be:
- Verifiable
- Impressive in context
- Specific (not "thousands")

## Case studies

Format:
- 1-2 sentence headline ("Apex Demo Transport cut CSA by 30% in 9 months")
- Customer logo + company info
- "The challenge / the solution / the result" structure
- Real metrics (with permission)
- Quote from named human
- Photos / screenshots
- Length: 500-1500 words for SEO + linkable

## Integration logos

Powerful trust signal: "Works with what you already use."
- Show logos of major integrations (Samsara, Motive, Stripe, etc.)
- Group by category (ELD / payment / etc.)
- Click → integration detail page

## Star ratings

Display if available:
- G2 / Capterra / TrustPilot widgets
- "4.8/5 from 200+ reviews" with link to source
- Don't fabricate

## What NOT to do

- "X people are viewing this right now" (manipulative if fake, creepy if real)
- Recent purchase popups ("Sarah from Texas just bought!") — outdated pattern
- Inflated counts ("10,000+ users" when actual is 200)
- Logos used without permission (legal + ethical problem)
- Testimonials from family / friends with fake titles
