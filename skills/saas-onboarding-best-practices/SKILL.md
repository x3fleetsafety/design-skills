# Saas Onboarding Best Practices

SaaS onboarding determines lifetime value. The user's first 30 minutes predict the next 30 months. Aim for a 'time to aha' of under 5 minutes for self-serve products.

## Time-to-value benchmarks

Under 60s — consumer freemium. Under 5 min — SaaS marketing tier. Under 30 min — enterprise. Under 1 day — complex implementation. If yours is longer, find the blocker.

## Checklist patterns

Persistent task list on dashboard. 4-7 items. Each completable in <5 min. Progress bar. Optional dismiss. Items pre-personalized to the customer's stated use case at signup.

## Sample data vs blank start

Blank start: forces commitment, real value. Sample data: faster aha, easier exploration. Most modern SaaS uses blank start + 'add your first X' empty-state guidance.

## Activation events

Define 1-2 explicit activation events ('user added a driver', 'user asked Compass a question'). Track them. Email sequences trigger on completion / non-completion.

## Common mistakes

Forcing a 12-step wizard. Hiding the actual product behind setup. Mandatory profile completion. No 'skip for now'. Demoing instead of letting user use the product.
